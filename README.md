# 麦克纳姆轮小车 · DRV8833 二线式 · 完整接线与使用说明

STM32F103C8T6 + 2× **DRV8833** 双路驱动模块 + PS2 手柄 + 4× 麦轮电机。

> 驱动是 **DRV8833**：每个通道只有 `IN1 / IN2` 两根输入 + `nSLEEP`，**没有 PWMA/PWMB**。
> 调速靠「符号-幅值」：正转给 IN1 灌 PWM、IN2 拉低；反转给 IN2 灌 PWM、IN1 拉低；停止两路都拉低。

### 2.3 电源（所有 GND 必须共地）

| 连接 | 说明 |
|---|---|
| 电池正极 → 两块驱动 **VM** | 电机电源（电压按电机） |
| 3.3V → 两块驱动 **VCC**（若有）+ PS2 **VCC** | 逻辑电源 |
| 所有 **GND** 连一起 | 主控、两块驱动、PS2、电池负极 |

> 建议在 **PB5（nSLEEP）到 GND 之间加 10kΩ 下拉电阻**，防止上电瞬间（MCU 复位那几毫秒）被误唤醒抖动。

## 四、手柄按键映射

| 输入 | 动作 |
|---|---|
| 左摇杆 上/下 | 前进 / 后退 |
| 左摇杆 左/右 | 左横移 / 右横移 |
| 右摇杆 左/右 | 原地左转 / 右转（临时占用，机械臂接入后归还） |
| **START** | **急停**（按住停车，松开恢复） |

机械臂按键（L1/R1/L2/R2/十字键/三角/方块/SELECT）已预留、暂不动作、**不会触发急停**。

## 五、上电 / 急停行为

- **上电 → 驱动睡眠**：PB5 输出低，芯片睡眠，四个电机物理断开，**绝对不动**。
- **连上手柄 → 唤醒**：第一次成功读到手柄后，程序才把 PB5 拉高。
- **手柄断开**：连续读失败 3 次（`PS2_LOST_LIMIT`）自动停车。
- **急停**：只有 START 键。

## 六、电机方向校准（车架空，30 秒）

`motor.h` 里四个 `MOTOR_*_INVERT`（当前默认反转右侧：LF=0 / LR=0 / RF=1 / RR=1）：

1. 上电、连手柄，推**左摇杆向上（前进）**。
2. 看四个轮子都应朝「让车前进」的方向转：
   - **某个轮子反了** → 只改那个轮的 `INVERT`（0↔1）；
   - **四个全反了**（整车变后退）→ 四个 `INVERT` 全部对调。
3. 前进对了，推**左摇杆向右**应纯横向右移（左前/右后反转、左后/右前正转）。若变斜走/自转 → 某个**麦轮辊子装反了**，需物理调换那个轮子。
4. 推**右摇杆左右**应原地左/右转。

速查表：

| 现象 | 改哪里 |
|---|---|
| 整车前进变后退 | `motor.h` 四个 `INVERT` 全部对调 |
| 单个轮子反 | 只改那个轮的 `INVERT` |
| 推左=右移、推右=左移 | `main.c` 的 `PS2_X_INVERT` 取反 |
| 推右摇杆右变左转 | `main.c` 的 `PS2_WZ_INVERT` 取反 |
| 推左摇杆没反应（右摇杆在动） | `ps2.h` 的 `PS2_SWAP_STICKS`（当前=1，改 0 试试） |
